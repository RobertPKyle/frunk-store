Commander Keen 4

Commander Keen 4: Secret of the Oracle

id Software's 1991 sequel, published by Apogee: the first part of "Goodbye, Galaxy!", with sloped floors, AdLib music and Keen hanging from ledges. The Shikadi plan to blow up the galaxy, and the Oracle of Gnosticus IV could say how to stop them, but its eight Council Members have been carried off. Pogo, jump and stun your way through the Shadowlands to find them. The shareware episode, in full.

Controls

Best with a controller. The on-screen buttons work too: the Touch / Controller button on the game's bar swaps between them.

Saves: Select (or Save 1) saves in the first of the game's six places. For another place, Start opens the menu: Save Game, a place, then a name typed with Keyboard (or none) and the top button. Load Game in the same menu brings a save back. Start then the bottom button goes back to the game; Start twice asks about quitting, which Start again backs out of. A keyboard plugged into the car works too: arrows move, Ctrl jumps, Alt pogos, Space fires, Enter is the status window, Esc the menu, F1 help.
